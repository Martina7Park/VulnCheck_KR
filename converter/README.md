# 컨버터 (점검자 PC)

회수한 점검 결과를 상세보고서 엑셀로 만듭니다. **이 폴더가 작업 폴더**입니다.

| 파일 | 용도 |
|------|------|
| `convert_v4.py` | **메인 — 이것 실행.** 결과 txt → 상세보고서 xlsx |
| `eos_checker.py` | EoS(지원 종료) 판정 — 컨버터가 자동 사용 |
| `kisa26_cases.json` | 2026 가이드 조치 사례 원문 — 주요정보 보고서의 보안가이드 시트 |
| `compare_results.py` | 이전·현재 보고서 비교 (`diff`) / 추세 (`trend`) |
| `check_patch.py` | 제품·버전별 CVE·패치 확인 (단독 실행) |
| `install_prereq.bat` / `.ps1` | Windows 에 Python + openpyxl 설치 |

```bash
pip install openpyxl          # 최초 1회 (Windows: install_prereq.bat)
python convert_v4.py          # 기준(전자금융/주요정보) → 대상(서버·웹WAS·DBMS·네트워크·보안장비·PC) 선택
```

이 폴더에 기준 엑셀(`전자금융기반시설_보안_취약점_평가기준(제2026-1호).xlsx`)을 두고, 결과를 아래 폴더에 넣습니다 (없으면 만드세요).

```
server/output/   webwas/output/   dbms/output/   security/output/   pc/output/   network/config/
```

## 판정값

`양호` / `취약` / `N-A` / `수동확인` / `점검불가` 다섯 가지입니다 (`N/A`·`NA`·`해당없음` 은 `N-A`, `점검 불가` 는 `점검불가` 로 정규화되고, 그 밖의 값은 경고 후 `수동확인`).

- `수동확인` : 자료는 수집했지만 사람이 판단해야 하는 경우
- `점검불가` : 점검 자체를 못 한 경우 (명령·권한 부족, 조회 오류, 타임아웃 등) — 근거에 사유가 적혀 있으니 해소 후 재점검
- 같은 항목이 여러 번 나오면 취약 > 점검불가 > 수동확인 > 양호 > N-A 순으로 채택

## 보안수준 산식

전체점수 A = **양호 + 취약** 항목 위험도값의 합 (수동확인·점검불가·N-A 제외), 취약점수 B = 취약 항목 위험도값의 합, 보안수준 = (A−B)/A×100.
A = 0 (판정된 항목이 하나도 없음) 이면 100% 가 아니라 **`산정불가`** 로 표시하고 평균에서 제외합니다. 미판정(수동확인+점검불가) 건수는 통계표 '미판정' 열에 표시되며, 확정 전까지 보안수준은 잠정치입니다.

## 선택 입력 파일 (분야 폴더 안: `server/` `webwas/` `dbms/` `network/` `security/` `pc/`)

| 파일 | 내용 |
|------|------|
| `scope.txt` | 보고서에 넣을 **호스트명 또는 IP** (한 줄에 하나, `#` 주석). 있으면 목록에 있는 대상만 포함하고 제외된 파일·호스트를 콘솔과 감사 로그(`logs/`)에 남깁니다. 없으면 전체 |
| `override.csv` | 인터뷰 결과 반영. UTF-8, 헤더 `호스트,항목코드,판정,근거`. 변환할 때 해당 항목 판정을 덮어쓰고 근거 앞에 `[인터뷰] 원래 판정: A → B` 를 남깁니다 (재실행만으로 반영, 원래 현황은 아래에 보존) |

같은 점검 대상의 결과 파일이 여럿이면 점검 일시가 **최신인 파일을 채택**하고 콘솔에 알립니다 (SRV 와 U 처럼 항목이 서로 다른 파일은 병합). 호스트명이 같고 IP 가 다르면 `호스트명(IP)` 로 구분합니다.

## 결과 파일 헤더 (점검 스크립트가 출력)

`# IP:` `# 실행 계정:` `# 클라우드:` `# DBMS 환경:` `# 실행 호스트:` 를 읽어 점검대상 시트의 IP 칸과 호스트 상세 시트(시스템 현황)에 표시합니다. `# DBMS 환경: 관리형 (RDS-MySQL)` 이면 기준 엑셀의 RDS·Aurora·Azure 열을 사용합니다.

## 보고서 구성

표지 / 개요 / 개정이력 / 점검대상 / 보안수준 통계 / 요약 통계 / 취약점 목록 / 검토·수정 / (보안가이드: 주요정보) / 호스트별 상세 / **증적 원문**

- 호스트 상세의 '현황 및 문제점' 에는 판정 근거와 함께 증적(명령 + 출력 **원문**)이 잘리지 않고 들어갑니다. 셀이 너무 길면(12,000자 초과) 앞부분 + `'증적 원문' 시트 N행 참조` 로 줄이고, 전체 원문은 '증적 원문' 시트에 항상 보존됩니다 (항목코드를 누르면 해당 행으로 이동). 마스킹된 값은 그대로입니다.
- 네트워크 config 의 SNMP community·비밀번호 해시·key 는 보고서에 마스킹해서 씁니다.
- A4 인쇄 설정(표지 제외)과 페이지 번호 바닥글이 모든 시트에 적용됩니다.
