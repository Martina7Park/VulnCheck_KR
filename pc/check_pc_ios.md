# iOS/iPadOS 보안 점검 체크리스트

iOS/iPadOS는 스크립트 실행이 불가능하므로 담당자가 설정 화면을 캡처하여 제출하고,
점검자가 아래 항목을 수동으로 판정합니다.

항목코드는 **다른 PC 점검(Windows/macOS 전자금융판 `check_pc.ps1`·`check_pc_mac.sh`)과 같은 `PC-01`~`PC-18` (2자리) 체계**입니다.
컨버터(`converter/convert_v4.py`)가 이 코드로 PC 분야를 판별하므로, 3자리 코드(`PC-001`)나 이 표에 없는 코드를 쓰면
결과 파일 전체가 분야 불일치로 제외됩니다. iOS 는 **전자금융 기준(PC)용**이며 주요정보(2026 상세가이드) PC 변환 대상이 아닙니다
(주요정보 PC 점검은 `check_pc_kisa.ps1` / `check_pc_mac_kisa.sh`).

## 점검 방법

담당자: 아래 각 항목의 **확인 경로**를 따라 설정 화면을 스크린샷으로 캡처 후 전달 (파일명에 항목코드 표기, 예: `PC-03_자동잠금.png`).
점검자: 스크린샷 기반으로 양호/취약/수동확인/점검불가/N-A 판정, 결과를 파이프 형식으로 기록.
- 스크린샷을 받지 못했거나 화면이 판독되지 않아 확인하지 못한 항목은 `점검불가` (사유 기재)
- 스크린샷으로 확인했으나 조직 정책 판단이 필요한 항목은 `수동확인`
- iOS 에 해당 기능이 없는 항목은 `N-A` (사유 기재)

```
PC-01|양호|화면 잠금 암호 설정됨 (Face ID + 암호)
PC-03|취약|자동 잠금 '안 함' 설정
```

## 점검 항목

기준값은 다른 PC 스크립트와 동일합니다: **암호 8자 이상 영문·숫자 조합**, **화면 잠금 대기 10분 이하**(iOS 선택지는 30초~5분이므로 '안 함'만 아니면 충족), **로그인 실패 잠금 임계값 5회 이하**(iOS 는 10회 실패 시 데이터 삭제 옵션 또는 기기 잠금 지연).

| 항목코드 | 점검 항목 (PC 공통 항목 체계) | 확인 경로 | 양호 기준 |
|----------|------------------------------|-----------|-----------|
| PC-01 | 패스워드 설정 (화면 잠금 암호) | 설정 > Face ID 및 암호 (또는 Touch ID 및 암호) | 암호가 설정됨 ('암호 켜기' 상태) |
| PC-02 | 패스워드 정책 (암호 길이·복잡도) | 설정 > Face ID 및 암호 > 암호 변경 > 암호 옵션 | **8자 이상** '사용자 설정 영숫자 암호' (6자리 숫자 암호는 취약) |
| PC-03 | 화면보호기/화면 잠금 | 설정 > 디스플레이 및 밝기 > 자동 잠금 / 설정 > Face ID 및 암호 > 잠금 중 접근 허용 | 자동 잠금 **10분 이하**('안 함' 아님, iOS 최대 5분), 잠금 중 제어 센터·알림 센터 등 접근을 최소로 허용 |
| PC-04 | 공유폴더 제거 (공유 기능) | 설정 > 일반 > AirDrop | '받지 않음' 또는 '연락처만' ('모든 사람' 은 취약) |
| PC-05 | 불필요 서비스 비활성화 (불필요 무선·자동 연결) | 설정 > Wi-Fi > 네트워크에 연결 확인, 설정 > 개인용 핫스팟 | 알 수 없는 네트워크 자동 연결 '끔' 또는 '알리기', 불필요한 개인용 핫스팟 끔 |
| PC-06 | 백신 설치 및 실시간 감시 (MDM/모바일 위협 방어) | 홈 화면/설정 > 일반 > VPN 및 기기 관리 | 조직 지정 MDM 또는 모바일 백신 설치·관리 중 |
| PC-07 | OS 보안 패치 | 설정 > 일반 > 소프트웨어 업데이트 (자동 업데이트 포함) | 최신 버전(또는 보안 패치) 설치됨 + 자동 업데이트 다운로드/설치 켜짐 |
| PC-08 | 방화벽 활성화 | - | N-A (iOS 는 앱 샌드박스 구조로 별도 호스트 방화벽 설정 없음) |
| PC-09 | 이벤트 로그 관리 | - | N-A (사용자 접근 가능한 이벤트 로그 설정 없음) |
| PC-10 | 원격 데스크톱 제한 | - | N-A (iOS 는 원격 데스크톱 서버 기능 없음; 원격 관리 MDM 프로파일은 PC-06 에서 확인) |
| PC-11 | 자동실행(AutoRun) 비활성화 | - | N-A (iOS 해당 기능 없음) |
| PC-12 | 이동매체(USB) 제한 | 설정 > Face ID 및 암호 > USB 액세서리 | '끔' (잠금 시 USB 차단) |
| PC-13 | Guest 계정 비활성화 | - | N-A (iOS 는 게스트 계정 없음; 기기 공유 시 '공유 iPad' 사용자 구성 확인) |
| PC-14 | 시스템 무결성 (탈옥·비인가 프로파일) | Cydia/Sileo 앱 존재 여부 확인, 설정 > 일반 > VPN 및 기기 관리 (프로파일 확인) | 탈옥 흔적 없음, 비인가 프로파일·사이드로드 앱 없음 |
| PC-15 | 브라우저 보안 설정 | 설정 > Safari > 사기성 웹 사이트 경고, 팝업 차단 | 두 항목 모두 켜짐 |
| PC-16 | 로그인 실패 잠금 임계값 | 설정 > Face ID 및 암호 > '데이터 지우기' | 켜짐 (10번 실패 시 데이터 삭제) 또는 MDM 으로 실패 횟수 제한 적용 |
| PC-17 | 감사 정책 | - | N-A (iOS 해당 기능 없음; 기기 감사는 MDM 서버 로그 확인) |
| PC-18 | 디스크 암호화 | 설정 > Face ID 및 암호 하단 '데이터 보호가 활성화되었습니다' / 설정 > [사용자] > iCloud > 고급 데이터 보호 | 암호 설정으로 데이터 보호 활성(기본), iCloud 백업은 고급 데이터 보호 켬 권고 |

참고(판정 코드 없음, 코멘트로 기록): VPN 설정(설정 > 일반 > VPN 및 기기 관리 > VPN, 조직 VPN 프로파일 설정 여부), 위치 서비스 앱별 권한(설정 > 개인정보 보호 및 보안 > 위치 서비스, 불필요 앱 '안 함').
이 두 항목은 PC 공통 항목 체계(PC-01~18)에 대응 코드가 없어 `#` 코멘트 줄로만 남깁니다.

## 제출 양식

담당자는 다음 형식으로 텍스트 파일을 작성하여 전달할 수도 있습니다.
**파일명은 `PC_<기기명>.txt`** 로 하고 `converter/pc/output/` 에 넣습니다 (증적을 첨부하려면 `<기기명>_pc_evidence.txt` 를 같은 폴더에 두고, 항목별 스크린샷 파일명·확인 내용을 `[PC-01] 12:00:00 설명` 형식으로 기록).

```
# ================================================================
# 점검 대상: [기기명/사용자명]
# OS: iOS [버전]
# 점검 기준: 전자금융기반시설 PC(업무용 단말) 자체 점검 항목 PC-01~18 (전자금융 평가기준에 PC 분야 없음)
# 점검 일시: [날짜]
# IP: 미확인
# 실행 계정: 수기 점검 ([점검자명])
# 클라우드: 없음
# ================================================================
PC-01|양호|Face ID + 암호 설정됨
PC-02|취약|6자리 숫자 암호 (8자 이상 영숫자 필요)
PC-03|양호|자동 잠금 2분
PC-04|양호|AirDrop '연락처만'
PC-05|양호|알 수 없는 네트워크 '알리기'
PC-06|양호|[MDM/백신 앱명] 설치됨
PC-07|양호|iOS 26.1 (최신), 자동 업데이트 켜짐
PC-08|N-A|iOS 해당 기능 없음 (앱 샌드박스)
PC-09|N-A|iOS 해당 기능 없음
PC-10|N-A|iOS 해당 기능 없음
PC-11|N-A|iOS 해당 기능 없음
PC-12|양호|USB 액세서리 끔
PC-13|N-A|iOS 게스트 계정 없음
PC-14|양호|탈옥 흔적·비인가 프로파일 없음
PC-15|양호|사기성 웹 사이트 경고·팝업 차단 켜짐
PC-16|양호|'데이터 지우기' 켜짐
PC-17|N-A|iOS 해당 기능 없음
PC-18|양호|데이터 보호 활성, 고급 데이터 보호 켜짐
```

이 형식은 `convert_v4.py` 의 PC 분야(전자금융)로 변환할 수 있습니다 (항목코드가 PC-01~PC-18 이고 헤더의 점검 기준에 '상세가이드(2026)' 문구가 없을 때).
확인하지 못한 항목은 `PC-xx|점검불가|사유` 로 기록합니다. 스크립트가 없으므로 결과 파일의 `# IP` / `# 실행 계정` / `# 클라우드` 헤더는 위 예시처럼 수기로 채웁니다.
